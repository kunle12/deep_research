2 · Background

Vision-language-action models condition a policy on camera observations and a natural-language instruction, emitting robot actions as tokens. The paradigm treats control as a continuation of language modelling.

2.1 · Tokenizing actions

Continuous actions are discretized into bins or encoded via VQ-VAE codebooks. Token granularity trades off dexterity against sequence length.

The key insight of the RT-2 lineage is that web-scale vision-language pretraining transfers to manipulation without any robot data being web-scale itself.
